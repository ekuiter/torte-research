##### Notes

- **Name**: The system name as used by its maintainers. We also include the project website, the canonical upstream (Git) repository, and relevant mirrors (which may have better availability, but can be less up-to-date).
- **#Releases**: For most systems, this is the number of Git tags.
- **System Software**: Here we justify why we consider this system to be system software.
- **Configuration Language**: The language used to define features and their dependencies.
- **Implementation**: The concrete implementation of the configuration-related tooling.
- **Row Updated**: When we last updated this row of the table (i.e., when we extracted the statistics).
